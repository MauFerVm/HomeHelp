# ProyectoLogin - Estructura PERN

## Instalación

### Backend
```bash
cd server
npm install
npm run dev
```
El servidor se ejecutará en `http://localhost:3002`.

### Frontend
```bash
cd client
npm install
npm run dev
```
La aplicación React correrá en `http://localhost:3000`.

## Scripts disponibles

- **server**
  - `npm run dev` - Levanta el servidor con nodemon.
  - `npm start` - Levanta el servidor con Node.

- **client**
  - `npm run dev` - Levanta la aplicación React con Vite.
  - `npm run build` - Construye la versión de producción.
  - `npm start` - Sirve la versión de producción.
